  def dijkstra(source: int) -> dict[int, float]:
    """
    Returns dict mapping each node to its shortest travel time from source.
    Uses a min-heap. Skips edges in CLOSED_EDGES.
    """
    import heapq
    dist = {n: float('inf') for n in ROAD_GRAPH.nodes}
    dist[source] = 0
    heap = [(0, source)]
    while heap:
      cost, u = heapq.heappop(heap)
      if cost > dist[u]:
        continue
      for v, data in ROAD_GRAPH[u].items():
        if (min(u,v), max(u,v)) in CLOSED_EDGES:
          continue
        new_cost = cost + data['weight']
        if new_cost < dist[v]:
          dist[v] = new_cost
          heapq.heappush(heap, (new_cost, v))
    return dist

  def shortest_path_cost(source: int, target: int) -> float:
    """Returns travel cost from source to target. Returns inf if unreachable."""
    return dijkstra(source)[target]

  def greedy_insert_order(order: dict, couriers: dict) -> tuple[str, int]:

    considering only couriers with enough remaining capacity:
      courier['capacity_max'] - courier['capacity_used'] >= order['weight']

  def dp_optimize_route(
    start_node: int,
    stops: list[int],
    time_budget_ms: float = 200.0
  ) -> tuple[list[int], float]:
    """
    Given a courier at start_node with a list of remaining stops to visit,
    find the optimal visiting order using DP (bitmask TSP variant).

    SCOPE LIMIT: If len(stops) > 8, truncate to first 8 stops (performance cap).

    DP formulation:
      state: (visited_bitmask, last_node)
      dp[mask][i] = min cost to have visited exactly the nodes in mask,
                    ending at stops[i]
      Transition: dp[mask | (1 << j)][j] = dp[mask][i] + cost(stops[i], stops[j])
      Base case: dp[1 << i][i] = cost(start_node, stops[i])

    TIME BUDGET: Check elapsed time after each mask iteration. If elapsed >
    time_budget_ms milliseconds, stop and return the best complete solution
    found so far. If no complete solution found yet, return the original stop
    order with its cost.

    Returns: (optimized_stop_order: list[int], total_cost: float)

    Use graph.shortest_path_cost(u, v) for all distance lookups.
    """

The simulator runs in a background asyncio task. It fires every 1 real second
(= 1 simulation tick). On each tick it:

  1. Advances tick counter by 1.
  2. Moves each active courier one step along their route (if they have stops
     remaining). If a courier reaches their next stop and that stop is a
     delivery node for an order, mark that order delivered, increment
     orders_delivered, add the travel cost to total_distance_driven.
  3. Every 4–7 ticks (random), fire one random disruption event (see below).
  4. Every tick where (tick - last_disruption_tick) >= 10, run DP
     re-optimization for each courier. Record greedy vs DP comparison.
  5. Append {tick, total_distance} to route_quality_history.
  6. Broadcast the full simulation state snapshot to all WebSocket clients.

DISRUPTION EVENTS (fire one randomly):

  A. new_order:
     - Generate order with random pickup node, random delivery node (different),
       random weight 3–15 kg, unique order_id = "ORD-{tick}-{random 3 digits}"
     - Call greedy_insert_order() to find best courier and position
     - Insert the order into that courier's route
     - Call check_capacity(); if over limit, call repack_courier()
     - Log event: {tick, type:"new_order", courier_id, insertion_index,
                   insertion_cost_delta, manifest_before, manifest_after,
                   algorithm:"Greedy Insertion"}
     - Set last_disruption_tick = tick

  B. road_closure:
     - Pick a random non-critical edge (avoid edges that would isolate a node)
     - Call close_road(u, v)
     - For each courier, recompute their route using get_shortest_path() on
       remaining stops (chain: current_pos → stop1 → stop2 → ...)
     - Log event: {tick, type:"road_closure", edge:(u,v),
                   algorithm:"Incremental Dijkstra",
                   couriers_rerouted: [list of courier ids]}
     - Reopen the road after 15 ticks (schedule a future tick callback)
     - Set last_disruption_tick = tick

  C. breakdown:
     - Pick a random active courier
     - Mark them as active=False
     - Redistribute all their remaining orders to the other two couriers
       using greedy_insert_order() for each order
     - Call repack_courier() if any receiving courier goes over capacity
     - Log event: {tick, type:"breakdown", courier_id,
                   orders_redistributed: int,
                   algorithm:"Greedy Insertion + Bin Packing"}
     - Respawn that courier at their starting node after 20 ticks
     - Set last_disruption_tick = tick

  D. priority_escalation:
     - Pick a random undelivered order from any courier
     - Move that order's pickup and delivery nodes to the front of that
       courier's route (index 0 and 1)
     - Log event: {tick, type:"priority_escalation", order_id, courier_id,
                   algorithm:"Route Resequencing"}
     - Set last_disruption_tick = tick
